# 光照控制台 V0.2 使用说明

这版上位机适配 p7 的 V1.8 固件，支持串口连接、状态显示、模式切换、远程亮度、校准/速度参数编辑、Flash 保存、实时曲线和 CSV 记录。所有命令自动添加 CRLF，不再需要手工输入 HEX。曲线使用 Tk Canvas，CSV 使用 Python 标准库，不增加依赖。

## 启动

1. 保留目前已经验收的 V1.8 固件，这一步不用重新下载程序。
2. 在旧串口助手中点击“关闭串口”，使 COM7 空闲，保持原有硬件接线。
3. 双击本文件夹的 start.cmd。当前电脑的独立 .venv 和 pySerial 已准备好；第一次迁移到其他电脑时启动脚本会建立独立环境并安装 requirements.txt。
   黑色启动日志窗口会一直保留，可最小化；使用期间不要关闭它。真正的操作页面是另一个标题为“STM32 光照控制台 V0.2”的窗口。启动失败时日志窗口会停留，便于查看错误。若旧版窗口仍开着，先正常关闭旧版，再重新双击 start.cmd。
4. 选择 COM7，点击“连接”。先显示“已打开 · 等待设备回复”，收到真实回复后才显示“设备已回复”。连接后会依次请求 STREAM ON、GET、CONFIG，不会自动修改亮度、校准或保存 Flash。
5. 若提示端口拒绝访问，关闭其他占用 COM7 的串口软件，再重新连接。如果串口号变化，断开后刷新列表并选择实际端口。

需要 Python 3.10 或更高版本，且包含 tkinter；当前电脑已用 Python 3.13 和 Tk 8.6 测试。依赖只安装在本文件夹的 .venv，不修改全局 Python 包。

## 四个页面

设备状态区始终显示开发板回复的实际模式、相对光照、目标/实际占空比、旋钮位置、光敏原始/平均值、估算电压。3 秒没有新 STATUS 时数值变灰并显示数据已过期，不将旧值当作实时测量。断开后清空显示。

“设备控制”：点击 AUTO / LOCAL / REMOTE 切换模式；只有确认处于 REMOTE 后，远程滑块和发送按钮才启用。拖动滑块只改变待发送值，点击“发送亮度”才下发指令。实际输出由上方 PWM 数值显示，仍按固件的渐变速度跟随目标。按实体按键可从 REMOTE 回 AUTO，上位机会同步显示该事件。

“实时曲线”：蓝色为相对光照，橙色虚线为目标占空比，绿色为实际占空比。纵轴统一为 0～100%，横轴从当前曲线首次收到状态时开始计秒，显示最近120秒，内存最多保留1200点。目标和实际值相同时曲线会重合。无效光照不画成0；连续状态间隔超过2秒时断开曲线，避免把缺失的数据连成一次缓慢变化。窗口重绘不会增加采样点，实际点数取决于收到的 STATUS，默认约每500ms一条。

曲线中的 Light 是校准范围内的相对明暗刻度，不是 lux；PWM 是固件报告的输出占空比，不是外部仪器测量的 LED 亮度。“清空曲线”只清空内存曲线，不修改设备和 CSV；重新连接也会清空曲线，避免连接前后的数据混在一起。

“参数与保存”：读取参数后填入编辑区。修改暗、亮参考和渐变间隔，点击“应用参数（RAM）”依次发送 CAL、RAMP、CONFIG；先在本地校验范围，再让设备确认。编辑值未应用时禁用 Flash 保存，防止误把旧参数保存。点击“保存到 Flash”才执行 SAVE；“载入已保存”执行 LOAD；“恢复默认（RAM）”执行 DEFAULTS，若要下次启动也恢复默认，随后保存。

“通信记录”：显示命令、回复、错误和事件，最多保留约 500 条窗口记录。默认不记录每条周期 STATUS，避免刷屏；勾选后可查看完整原始数据。清空只影响窗口显示，不修改设备或文件。

底部文本命令框用于输入单条命令，例如 GET、CONFIG、HELP，按回车或点击发送即可。软件统一补换行；拒绝多行、非 ASCII 字符和超过 63 字符的命令。

## CSV 记录

1. 连接并收到设备回复后，进入“实时曲线”，点击“开始 CSV 记录”。选择文件位置，默认在本目录的 records 文件夹，文件名带当前时间；取消选择不会开始记录。
2. 开始后自动发送 STREAM ON，恢复周期上报。下方显示记录中、有效行数和完整保存路径。只有开始以后收到的有效 STATUS 才写入，不补写之前的曲线历史，也不把 OK、错误提示或界面刷新写成数据。
3. 进行遮挡光敏、转旋钮或远程调光测试。测试结束点击“停止并保存”，待状态变为“已停止”，再用 Excel/WPS 打开 CSV。停止记录后周期上报和曲线仍继续；再次记录会选择新的文件。
4. 正常断开、串口错误导致线程退出或关闭控制台时，也会关闭并保存已有 CSV。未收到 STATUS 时行数保持不变；不会用旧值补齐。硬件掉电但 USB 模块仍在时，系统可能暂时无法识别断开，此时可手动停止记录。

CSV 使用 UTF-8 BOM 编码，便于 Excel/WPS 打开，字段如下：

| 字段 | 含义 |
| --- | --- |
| time_iso | 电脑收到该行的时间，含时区；不是 MCU 采样时刻 |
| elapsed_s | 从开始记录到收到该行经过的秒数，使用单调时钟 |
| mode | AUTO / LOCAL / REMOTE |
| adc_raw / adc_avg | 光敏 ADC 原始值 / 滑动平均值，0～4095 |
| voltage_mV | 根据滤波 ADC 估算的毫伏值 |
| light_percent | 校准后的相对光照百分比，0～100 |
| target_percent / pwm_percent | 目标 / 实际 PWM 占空比，0～100 |
| pot_raw / knob_percent | 旋钮 ADC 原始值 / 百分比 |
| remote_percent / rx_errors | 保存的远程目标 / 固件累计串口接收错误数 |
| cal_dark / cal_bright / ramp_ms | 最近一次确认的暗参考 / 亮参考 / 渐变间隔 |

错误的传感器字段留空，参数发生改变但新 CONFIG 尚未确认时，三个配置字段留空，不将未知值记为0。数据约每1秒刷新到文件，正常停止会关闭文件并完成刷新；强制结束进程或电脑掉电可能丢失末尾尚未刷新的数据。磁盘写入失败时会提示并停止记录，已有文件可以保留检查。

## 本轮曲线与记录验收

1. AUTO 下保持正常光照几秒，再用手遮挡、移开：蓝线应随明暗变化，目标应约为100减去光照，绿线按渐变速度跟随目标。
2. 切 REMOTE，先发送20%，稳定后发送80%：橙线应切换目标，绿线逐步变化。环境不变时蓝线应基本稳定；若 LED 直接照到光敏电阻，仍可能影响光照读数。
3. 开始 CSV 记录，完成上述变化约15～30秒；确认行数增加。中途点击“清空曲线”，文件行数应继续增加。停止保存，检查 CSV 的 PWM 变化和界面相符。
4. 开始另一次记录后正常断开；CSV 应显示已停止，能正常打开。重新连接后记录按钮恢复可用，曲线从新一轮数据开始。

## 第一轮验收

1. 连接后看状态是否持续更新，参数页是否显示 Dark=3764、Bright=481、RampMs=40（或设备实际保存值），Saved/Dirty 是否与设备一致。
2. 点击 REMOTE，拖到20%，点击发送；再设80%，等待 LED 逐渐变亮。只拖滑块不点发送时设备不应改变目标。
3. 按实体按键，应回到 AUTO，上位机远程发送按钮禁用。再点 LOCAL，转动电位器，设备实际输出和界面状态应同步变化。
4. 参数页把渐变间隔改为100，点击应用，确认“RAM 有未保存参数”；保存后变成“与已保存参数一致”。复位开发板，读取参数仍为100。最后恢复默认并保存，回到实测校准及40ms/百分点。
5. 断开并重新连接，确认串口能释放、重新打开，状态能恢复。设备处于 REMOTE 时断开上位机，固件保持最后有效目标；需要恢复自动控制时按实体按键。

## 错误处理

串口读写在后台线程中执行，不直接操作 Tk 控件。主线程每50ms处理事件。命令队列一次只等待一条命令的有效回复；设备拒绝或约3秒无回复后，会取消后续排队操作，不自动重发 SAVE 等写入命令。参数批次整体检查队列容量，避免只排入一半操作。

设备无回复不等同于 USB 串口没打开。请检查开发板供电、B10→模块 RXD、B11→模块 TXD 和共地；恢复后点击查询状态或重新连接。部分参数操作已成功、后续命令超时时，应重新读取参数核对，不能假设整批操作已全部完成或全部撤销。

当前固件没有请求ID，GET 的回复类型与周期 STATUS 相同；上位机按回复类型和命令关键字匹配，不能对相同类型的延迟回复作严格请求关联。连接时清空 PC 接收缓存，降低旧数据干扰。USB模块还在、但开发板掉电时操作系统不一定报拔出；软件会提示数据过期、查询超时，需要用户恢复连接，不自动切换固件模式。
