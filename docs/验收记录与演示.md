# 光照监测与自动调光系统：验收记录与演示

固件：p7 V1.8；上位机：pc_app V0.2。

验收结论：2026-11-12，用户确认最后两项持续运行、断开重连检查均无问题。本轮计划的功能验收完成，可将当前固件与上位机作为第一个完整项目版本保留。

## 项目范围

利用 STM32F103C8 采集光敏模块和电位器信号，完成光敏滑动平均、明暗参考校准、OLED 显示、三种调光模式及 PWM 渐变。电脑通过串口进行控制、参数读写、曲线显示与 CSV 记录，校准和渐变参数支持内部 Flash 保存。

AUTO 的目标为 `100 - 相对光照`；LOCAL 的目标来自旋钮；REMOTE 的目标来自电脑。相对光照是当前校准范围内的百分比，不是 lux；当前控制方式是根据环境明暗映射输出，没有实现维持指定照度的闭环控制。

| 模式 | 行数 | 检查结果 |
| --- | --- | --- |
| LOCAL | 75 | 本次旋钮范围0%～54%，所有行 Target=Knob；本次记录未覆盖旋钮高端，之前已单独确认0%～100%可用 |

## 最后一轮整体验收

测试前保持已验证的接线和固件，关闭占用同一串口的其他软件；不要重新下载固件。

| 操作 | 预期结果 | 本轮结果 |
| --- | --- | --- |
| 开始一个新的 CSV 记录，AUTO 下遮挡并移开光敏模块 | 光照、目标和输出随环境变化；数据行数持续增加 | 已有单独记录及综合记录 |
| 点击 LOCAL，把旋钮转向低端、再转向高端 | Target 跟随 Knob，PWM 渐变跟随 Target；光照不决定该模式目标 | 本轮0%～54%映射正确；全量程此前已确认 |
| 点击 REMOTE，发送20%，稳定后发送80% | Target 分别为20%、80%，PWM 渐变跟随；旋钮不决定该模式目标 | 综合记录确认两个目标均到达 |
| REMOTE 下按一下实体按键 | OLED 和上位机回到 AUTO，电脑远程亮度发送按钮禁用 | 用户反馈本轮流程完成；CSV确认REMOTE→AUTO |

| 新开一次记录，点击断开，再重新连接 | 断开后记录停止、文件可打开；重连后状态恢复，曲线重新开始；记录需手动重新开始 | 用户确认无问题 |
| 连接后保持运行约5分钟，间隔操作遮挡、旋钮和模式切换 | 界面持续响应、状态继续更新，没有无法恢复的串口错误 | 用户确认无问题 |

旋钮两端不必刚好对应严格的0和4095，以实际能接近0%～100%且变化连续为准。三条曲线有相同数值时会重合，橙线被绿线部分覆盖属于正常显示。

如果测试发现异常，保留当次 CSV 和通信记录，根据发生时的模式、目标、实际 PWM 与 RxErr 定位，不一次改动多个模块。

## 建议的项目演示顺序

1. 介绍硬件：光敏输入、电位器、LED、按键、OLED、USB转串口。
2. AUTO 演示遮挡补光；指出目标立即改变而实际 PWM 渐变。
3. LOCAL 演示旋钮调光；REMOTE 演示电脑20%/80%调光，再用实体按键回到 AUTO。
4. 展示曲线和一份包含三种模式的 CSV。
5. 展示参数读取、修改和保存。掉电恢复功能按 README.md 中已验证的流程说明或演示，勿反复擦写作为无意义压力测试。
